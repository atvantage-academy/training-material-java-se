Plattform und Release-Modell

Wie Java heute erscheint – und was das für Deinen Umstieg heißt · Java-Update

Früher kam ein Release, wenn es fertig war – heute, wenn der Zug fährt

  • Was nicht fertig ist, fährt mit dem nächsten Zug
  • Weniger auf einmal – jedes Release ist ein kleiner Schritt

Alle zwei Jahre hält der Zug an einem LTS-Release

  • Dazwischen: gleich stabil, aber nur bis zum nächsten Release gepflegt
  • Im Kurs trägt jedes Feature die Marke seines LTS-Release

Jedes Quartal kommt ein Update – kein neues Release

21Feature. 0Interim. 12Update. 1Patch
  • Januar · April · Juli · Oktober, jeweils am dritten Dienstag
  • Sicherheit und Fehler – keine neuen Sprachmittel
  • Wer ein Quartal auslässt, läuft mit bekannten Lücken

Java ist eine Spezifikation – Dein JDK kommt von einem Anbieter

  • Technisch weitgehend gleich – verschieden in Fristen, Plattformen, Lizenz
  • „Oracle JDK“ ist nicht „OpenJDK“: eigene Lizenz, kostenfrei nur auf Zeit

Wie lange es Updates gibt, entscheidet Dein Anbieter

  • Eclipse Temurin, jeweils „mindestens bis“ – andere Anbieter haben andere Fristen
  • Oracle mit Vertrag: 21 bis 09/2031, 25 bis 09/2033
  • Builds von jdk.java.net: nur bis zum nächsten Feature-Release

Stand Oktober 2026 · adoptium.net/support · Oracle Java SE Support Roadmap

Ein JEP ist der Fahrplan für ein Feature

Vorschlag
Draft→Submitted→Candidate
Für ein Release
Proposed to Target→Targeted→Integrated→Complete
Ausgeliefert
Closed / Delivered
Aufgegeben
Closed / Withdrawn
  • JDK Enhancement Proposal: Nummer, Begründung, Ziel-Release
  • „Candidate“ ist eine Idee, keine Zusage – fest wird es erst mit Targeted
  • Der Schlüssel zum Nachschlagen: die JEP-Nummer

  • Incubator: neue API im Modul jdk.incubator.*
  • Preview: fertig spezifiziert, aber nur mit --enable-preview – und nur auf genau diesem JDK
  • Erst die finale Fassung gehört in Produktion

Incubator, Experimentell, Preview – dreimal „noch nicht fertig“

Incubator Experimentell Preview
Was eine neue API eine JVM-Funktion (GC, JIT) ein Sprachmittel oder eine API
Reifegrad API kann sich noch grundlegend ändern läuft, aber nicht produktionsreif fertig spezifiziert, wartet auf Rückmeldung
Einschalten --add-modules jdk.incubator.… -XX:+UnlockExperimentalVMOptions --enable-preview beim Übersetzen und Starten
Beispiel HTTP-Client (9, 10), Vector API ZGC (11), Shenandoah (12) Records (14, 15), String Templates
  • Incubator und Preview betreffen Deinen Code, Experimentell nur den Start der JVM
  • Preview-Code läuft nur auf genau dem JDK, mit dem er übersetzt wurde
  • Gemeinsam: Jede Stufe kann sich ändern oder wieder verschwinden

Preview heißt Probefahrt

String gruss = STR."Hallo \{name}!";
  • Die String Templates waren Preview in 21 und 22 – und sind in 23 ersatzlos zurückgezogen
  • Code, der sie nutzt, übersetzt mit keinem JDK mehr
  • Warum, und was es stattdessen gibt: Die Geschichte der String-Interpolation in Java

Zum Nachschlagen: LTS-Evolution und JEP-Landkarte

  • Java-LTS-Evolution – je LTS-Release die wichtigsten Features, mit kurzer Erklärung und Codebeispiel
  • JEP-Landkarte – jeder JEP als Zeile mit seinem Weg vom Vorschlag über Incubator und Preview bis final oder entfernt
    • filterbar nach Anwendungsart, LTS-Sprung und Bereich
    • je JEP: worum es geht, Umsetzung und Kompatibilitätsrisiko, Beispiel
  • Von einem LTS-Release der Evolution führt „Alle JEPs dieser Version →“ in die Landkarte
