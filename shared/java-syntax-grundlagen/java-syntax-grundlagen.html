Java-Syntax auf einen Blick

Die Java-Grundsyntax auf wenigen Seiten: Womit rechnet Java, wie schreibst Du Variablen, Methoden und Kontrollstrukturen – und was passiert beim Umwandeln von Typen? Gedacht als Nachschlagewerk beim Übertragen vertrauter Konstrukte in Java.

1 Jedes Programm startet in main

Die klassische Schreibweise

public class HelloWorld {

    // Einstiegspunkt: hier startet die JVM
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Der Dateiname muss zum Klassennamen passen: HelloWorld.java. Die JVM sucht beim Start genau diese Methode – public static void main(String[]). In args stehen die Argumente von der Kommandozeile.

Die verkürzte Schreibweise ab Java 25

void main() {
    IO.println("Hello, World!");
}

Seit Java 25 (16. September 2025) darf eine Quelldatei ohne Klasse auskommen, main weder public noch static sein und die Parameterliste entfallen; IO.println steht ohne Import bereit. Von Java 21 bis 24 gab es das nur als Vorschau-Feature. Gedacht für kleine Programme und den Einstieg – in diesem Kurs bleiben wir bei der klassischen Form.

Ganzzahl-Literale: vier Schreibweisen

int dezimal = 42;

// hexadezimal, Präfix 0x → 42
int hexadezimal = 0x2A;

// binär, Präfix 0b → 42
int binär = 0b101010;

// oktal, führende 0 → 42
int oktal = 052;

// Unterstriche als Trenner, nur fürs Auge
int lesbar = 1_000_000;

Alle vier Zeilen erzeugen denselben Wert – nur die Notation unterscheidet sich.

Ein Suffix legt den Typ des Literals fest: 9_000_000_000L ist ein long (ohne L wäre es ein zu großes int), 3.14f ein float statt eines double.

Zeichen: char und Escape-Sequenzen

char a = 'A';
char umlaut = 'ä';

// Unicode-Escape: dasselbe Zeichen wie 'ä'
char gleich = '\u00e4';

// Escape-Sequenzen: \t \\ \' \" ebenso
char zeilenende = '\n';

// char ist eine Zahl: 65
int code = a;

Unicode-Escapes stehen für ein Zeichen – auch in Zeichenketten: "Gr\u00fc\u00dfe" ist dasselbe wie "Grüße".

Merke: Nachkommastellen mit float/double rechnen binär und runden ungenau – Geldbeträge führt man deshalb als ganze Cent in int oder long.

3 Syntax-Grundlagen

Deklaration von Variablen

// deklarieren
int anzahl;

// zuweisen
anzahl = 3;

// beides in einem Schritt
int summe = 0;

// Konstante: nur einmal zuweisbar
final int MAX_KONTEN = 5;

// MAX_KONTEN = 6;  → Fehler, MAX_KONTEN ist final

Der Typ steht immer vor dem Namen. final heißt: genau einmal zuweisbar – die Variable ist danach eine Konstante.

Typ ableiten lassen: var

// der Compiler leitet den Typ aus der Zuweisung ab
var anzahl = 3;          // int
var name = "Ada";        // String
var preis = 9.99;        // double

// spart die Wiederholung langer Typnamen
var buchungen = new ArrayList<Buchung>();
// statt: ArrayList<Buchung> buchungen = new ArrayList<Buchung>();

// var anzahl;        → Fehler, ohne Zuweisung kein Typ
// var leer = null;   → Fehler, null hat keinen Typ
// anzahl = "drei";   → Fehler, anzahl bleibt int

Voraussetzung: Deklaration und Zuweisung stehen in einer Anweisung – nur daraus kennt der Compiler den Typ. var gibt es nur für lokale Variablen, nicht für Attribute, Parameter oder Rückgabetypen. Vorteile: weniger Wiederholung, kürzere Zeilen, der Name rückt in den Blick. Der Typ steht trotzdem fest – Java bleibt statisch typisiert. Ist der Typ rechts nicht offensichtlich, schreibt man ihn besser aus.

Blöcke, Umbrüche, Einrückung

// { … } fasst Anweisungen zu einem Block zusammen
if (betrag > 0) {
    // jede Anweisung endet mit einem Semikolon
    einzahlen(betrag);
}

// gleichwertig für den Compiler, nur schlechter zu lesen
if (betrag > 0) { einzahlen(betrag); }

Zeilenumbrüche und Einrückung sind dem Compiler egal – sie dienen den Lesenden. Struktur entsteht durch { } und ;.

Bezeichner: erlaubt ist viel

// Umlaute sind erlaubt
int zähler = 0;

// derselbe Name als Unicode-Escape geschrieben – der
// Compiler liest in beiden Zeilen „zähler“, die Zeile
// wäre also eine doppelte Deklaration:
// int z\u00e4hler = 0;

// die Länge ist unbegrenzt
int anzahlDerOffenenKontenImBestand;

// zwei verschiedene Variablen: Java ist case-sensitive
int wert, Wert;

Java ist case-sensitive. Namen dürfen Buchstaben (auch Umlaute), Ziffern, _ und $ enthalten, aber nicht mit einer Ziffer beginnen. Üblich sind lowerCamelCase für Variablen und Methoden, UpperCamelCase für Klassen, GROSS_MIT_UNTERSTRICH für Konstanten.

Kommentare

// bis zum Zeilenende

/* über mehrere
   Zeilen */

/** Javadoc – beschreibt das, was danach kommt. */

4 Strings und Arrays

StringLänge: length()

String iban = "DE02120300000000202051";

// Länge über die Methode length()
int länge = iban.length();

// einzelnes Zeichen, zählt ab 0 → 'D'
char erstes = iban.charAt(0);

// Teilstring → "DE"
String kurz = iban.substring(0, 2);

// + verkettet Zeichenketten
String zusammen = "IBAN: " + iban;

Ein String ist unveränderlich: Jede Operation liefert ein neues Objekt, das Original bleibt, wie es war.

ArrayLänge: length

// drei Elemente, alle mit dem Wert 0
int[] beträge = new int[3];

// Zugriff über den Index, ab 0
beträge[0] = 1250;

// length ist ein Feld, keine Methode → 3
int anzahl = beträge.length;

// direkt mit Werten füllen
int[] direkt = { 1250, -300, 80 };

// beträge[3] = 1;  → ArrayIndexOutOfBoundsException

Die Länge steht bei der Erzeugung fest und lässt sich nicht ändern. Wer wachsen können muss, nimmt später eine List.

Achtung: length ohne Klammern gilt für Arrays, length() mit Klammern für String – eine klassische Stolperstelle.

5 Typumwandlung: implizit und explizit

Implizit – der Compiler wandelt selbst

int cent = 1250;

// int → long
long groß = cent;

// int → double: 1250.0
double genau = cent;

char c = 'A';

// char → int: 65
int code = c;

Erlaubt, solange der Zieltyp größer ist und nichts verloren gehen kann: byte → short → int → long → float → double.

Explizit – Du entscheidest, mit Verlust

double zins = 12.99;

// schneidet ab, rundet nicht → 12
int cent = (int) zins;

int groß = 200;

// passt nicht in 8 Bit, Überlauf → -56
byte klein = (byte) groß;

// int falsch = zins;  → Fehler, der Cast fehlt

Der Cast (typ) ist Deine Zusicherung, den möglichen Verlust in Kauf zu nehmen.

Merke: Java wandelt niemals stillschweigend in einen kleineren Typ. Fehlt der Cast, meldet es der Compiler – nicht erst die Laufzeit.

6 Methoden: Signatur, Rückgabe, Überladen

Aufbau und Signatur

static int sumCents(int[] amounts) {
    int summe = 0;
    for (int a : amounts) {
        summe += a;
    }
    // liefert den Wert an den Aufrufer zurück
    return summe;
}

Die Signatur ist Name + Parametertypen: sumCents(int[]). Der Rückgabetyp gehört nicht dazu.

void oder Rückgabewert

static void ausgeben(int cent) {
    System.out.println(cent + " Cent");

    // return;  wäre optional und bricht früher ab
}

static boolean istPositiv(int cent) {
    // Pflicht bei jedem Rückgabetyp außer void
    return cent > 0;
}

void heißt: liefert nichts zurück. Bei allen anderen Rückgabetypen muss jeder Pfad ein return erreichen.

Überladen (Overloading)

static String format(int cent) {
    return cent / 100 + "," + Math.abs(cent % 100);
}

static String format(int cent, String währung) {
    return format(cent) + " " + währung;
}

Gleicher Name, verschiedene Parameterlisten – also verschiedene Signaturen. Der Compiler wählt anhand der Argumente aus. Ein anderer Rückgabetyp allein genügt nicht.

7 Kontrollstrukturen und Blöcke

Verzweigung und ?:

if (saldo > 0) {
    System.out.println("im Plus");
} else if (saldo == 0) {
    System.out.println("ausgeglichen");
} else {
    System.out.println("im Minus");
}

String text = saldo >= 0
        ? "im Plus"
        : "im Minus";

Der Bedingungsoperator ?: ist ein Ausdruck: Er liefert einen Wert, statt Anweisungen auszuführen.

switch

switch (kontoart) {
    case "giro":
        gebühr = 0;
        // ohne break läuft es in den nächsten case weiter!
        break;
    case "spar":
        gebühr = 100;
        break;
    default:
        gebühr = 50;
}

Zählschleife: klassisches for

for (int i = 0; i < beträge.length; i++) {
    System.out.println(beträge[i]);
}

Start · Bedingung · Fortschaltung – passend, wenn Du den Index brauchst.

Durchlaufen: for-each

for (int betrag : beträge) {
    System.out.println(betrag);
}

Kürzer und weniger fehleranfällig, wenn der Index egal ist.

Kopfgesteuert: while

int rest = betrag;
while (rest > 0) {
    rest -= abbuchen(rest);
}

Prüft vor dem ersten Durchlauf – der Rumpf läuft womöglich nie.

Fußgesteuert: do-while

int versuch = 0;
do {
    versuch++;
} while (versuch < 3);

Prüft nach dem Durchlauf – der Rumpf läuft mindestens einmal.

Gültigkeit: eine Variable lebt nur in ihrem Block

if (saldo > 0) {
    int bonus = 10;        // entsteht hier …
    System.out.println(bonus);
}                          // … und endet hier

// System.out.println(bonus);   // Fehler: bonus ist unbekannt

for (int i = 0; i < 3; i++) { }
// System.out.println(i);       // Fehler: i gehört zum for-Block

Alles zwischen { und } ist ein Block. Was darin deklariert wird, ist außerhalb nicht sichtbar – deshalb wandern Variablen, die länger leben sollen, vor den Block.
