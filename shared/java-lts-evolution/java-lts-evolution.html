Java-LTS-Evolution

Eine interaktive Zeitleiste der Java-Versionen von 1.0 bis 25. Klicke eine Version an, um ihre wichtigsten Sprach- und API-Features samt kurzem Code-Beispiel zu sehen. LTS-Versionen sind markiert, und ab Java 8 nennt jedes Feature seine JEPs – ein Klick auf die Nummer führt zur Beschreibung bei openjdk.org. Über das Druckersymbol oben rechts entsteht eine lineare Übersicht aller Versionen (auch als PDF).
