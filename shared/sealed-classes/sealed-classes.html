Sealed Classes

Mit sealed legt eine Klasse oder ein Interface fest, wer davon erben darf – und nur diese. Der Compiler kennt damit alle Unterarten und kann prüfen, dass Du jede behandelst. Stell die Hierarchie unten um und sieh, was er dazu sagt.

seit Java 17 LTS 17 JEP 409 switch darüber: LTS 21, JEP 441

Warum es das gibt: Records, Sealed Classes und Pattern Matching gehören zusammen – sie sind Javas Umsetzung der datenorientierten Programmierung. Woher die Idee kommt und wofür sie sich lohnt, zeigen die Folien Datenorientierte Programmierung.

1 · Was sealed bedeutet

Eine sealed Klasse oder ein sealed Interface nennt hinter permits alle Unterarten, die es geben darf – andere lehnt der Compiler ab.

public sealed interface Zahlart permits Rechnung, Lastschrift, Kreditkarte, PayPal { }

Dafür gelten zwei Bedingungen:

  • Jede erlaubte Unterart entscheidet, wie es unter ihr weitergeht: final (Schluss), sealed (wieder abgeschlossen, mit eigener Liste) oder non-sealed (ab hier offen, siehe unten). Records und Enums sind von sich aus final.
  • Alle Unterarten liegen nah beieinander: in derselben Datei, ohne Modulsystem im selben Paket, mit Modulsystem im selben Modul.

Dieselbe Datei

Stehen alle Unterarten in derselben Quelldatei, darf permits fehlen – der Compiler nimmt die, die er dort findet.

sealed interface Form { }
record Kreis(double r) implements Form { }
record Quadrat(double a) implements Form { }

Dasselbe Paket

Ohne Modulsystem (Klassenpfad, unbenanntes Modul) müssen alle Unterarten im selben Paket liegen.

error: class Form in unnamed module cannot extend
       a sealed class in a different package

Dasselbe Modul

Mit module-info.java dürfen sie in verschiedenen Paketen liegen, aber nur im selben Modul. Fremde Bibliotheken können eine versiegelte Hierarchie also nie erweitern.

Was gibt Fehler?

Zwei Dinge lehnt der Compiler ab: eine Unterart, die sich nicht entscheidet, und eine, die nicht in permits steht.

Was bedeutet non-sealed?

Mit non-sealed öffnet eine erlaubte Unterart die Hierarchie unter sich wieder: Von ihr darf jede Klasse erben, ohne irgendwo zu stehen.
