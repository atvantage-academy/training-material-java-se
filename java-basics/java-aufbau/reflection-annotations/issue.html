    Räume zur Laufzeit befragen

    User Story

    Als Entwickler:in der Raumbuchung möchte ich verstehen, wie Frameworks Klassen zur Laufzeit untersuchen und Stellvertreter erzeugen, damit mich JUnit, Jackson oder Mockito nicht mehr wie Magie anmuten.

    Lernziele
    • Du listest die Felder einer Klasse auf, rufst eine Methode über ihren Namen auf und liest ein privates Feld.
    • Du erklärst, warum das Modulsystem den Zugriff auf private Felder des JDK verweigert.
    • Du schreibst eine eigene Annotation mit @Retention und @Target und wertest sie per Reflection aus.
    • Du erzeugst mit Proxy und InvocationHandler einen Stellvertreter, der jeden Aufruf protokolliert.
    Definition of Done

    Reflection

    • Die Tests listsDeclaredFields, callsMethodByName und readsPrivateField tragen kein @Disabled mehr und sind grün.
    • Die Vorhersage in readsPrivateFieldOfString hast Du notiert, geprüft und die Assertion korrigiert.

    Eigene Annotation

    • @Required steht an id und name von Room.
    • Beide Tests in ValidatorTest tragen kein @Disabled mehr und sind grün.

    Dynamic Proxy

    • logsEveryCallAndDelegates trägt kein @Disabled mehr und ist grün, ohne dass Du InMemoryRoomCatalog geändert hast.
    • Die Vorhersage in proxyForAClass hast Du notiert, geprüft und die Assertion korrigiert.
    • mvn test läuft ohne Fehler und ohne übersprungene Tests durch.

    Für die ganze Seite

    • Du hast die Kontrollfragen beantwortet

    JUnit findet Deine Testmethoden, ohne dass Du sie irgendwo einträgst. Jackson schreibt Objekte als JSON, ohne dass Du Getter aufzählst, und Mockito erzeugt Objekte zu Interfaces, die niemand implementiert hat. Alle drei tun das mit den Mitteln, die Du in drei Aufgaben selbst ausprobierst: Reflection, Annotationen und Dynamic Proxies.

    Arbeitsschritte

    Reflection: Lege das Paket an und kopiere den Code

    Leg in Deinem Projekt aufbau das Paket aufbau.reflection an, unter src/main/java und unter src/test/java. Kopiere die folgenden Klassen nach src/main/java/aufbau/reflection.

    Room.java:

    package aufbau.reflection;

public class Room {

    private String id;
    private String name;
    private int seats;

    public Room(String id, String name, int seats) {
        this.id = id;
        this.name = name;
        this.seats = seats;
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public int getSeats() {
        return seats;
    }

    public String label() {
        return id + " " + name;
    }
}

    Reflection: Befrag die Klasse Room

    Implementier die drei Methoden in ReflectionTools. Entferne an den ersten drei Tests in ReflectionToolsTest jeweils @Disabled, sobald Du die Methode dazu angehst, und mach sie grün.

    Hinweis: Alles beginnt bei einem Class-Objekt: Room.class oder target.getClass(). Sieh Dir dort getDeclaredFields, getMethod und getDeclaredField an, an Method die Methode invoke, an Field die Methoden setAccessible und get.

    Reflection: Sag den Zugriff auf String vorher

    Der Test readsPrivateFieldOfString trägt @Disabled. Er versucht, mit Deinem readField das private Feld value eines String zu lesen.

    1. Notier Deine Erwartung: Klappt das wie bei Room?
    2. Entferne @Disabled und starte den Test.
    3. Erklär das Ergebnis.
    4. Korrigier die Assertion auf das tatsächliche Verhalten, bis der Test grün ist.

    Annotation: Schreib @Required

    Schreib in src/main/java/aufbau/reflection eine Annotation Required, die man an Felder schreiben kann und die zur Laufzeit erhalten bleibt. Setz sie in Room an die Felder id und name.

    Hinweis: Eine Annotation ist ein @interface. Ob sie zur Laufzeit da ist, entscheidet @Retention, wo man sie hinschreiben darf, @Target.

    Proxy: Kopiere den Raumkatalog

    Kopiere die folgenden Typen nach src/main/java/aufbau/reflection.

    RoomCatalog.java:

    package aufbau.reflection;

import java.util.Optional;

public interface RoomCatalog {

    void add(Room room);

    Optional<Room> find(String id);
}

    InMemoryRoomCatalog.java:

    package aufbau.reflection;

import java.util.HashMap;
import java.util.Map;
import java.util.Optional;

public class InMemoryRoomCatalog implements RoomCatalog {

    private final Map<String, Room> rooms = new HashMap<>();

    @Override
    public void add(Room room) {
        rooms.put(room.getId(), room);
    }

    @Override
    public Optional<Room> find(String id) {
        return Optional.ofNullable(rooms.get(id));
    }
}

    Kopiere den Test nach src/test/java/aufbau/reflection.

    LoggingProxyTest.java:

    package aufbau.reflection;

import static org.junit.jupiter.api.Assertions.assertDoesNotThrow;
import static org.junit.jupiter.api.Assertions.assertEquals;

import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Proxy;
import java.util.ArrayList;
import java.util.List;
import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

class LoggingProxyTest {

    @Test
    @Disabled("Remove @Disabled once you have implemented LoggingProxy.wrap")
    void logsEveryCallAndDelegates() {
        List<String> log = new ArrayList<>();
        RoomCatalog catalog = LoggingProxy.wrap(new InMemoryRoomCatalog(), RoomCatalog.class, log);

        catalog.add(new Room("R101", "Berlin", 6));
        String name = catalog.find("R101").orElseThrow().getName();

        assertEquals("Berlin", name);
        assertEquals(List.of("add", "find"), log);
    }

    @Test
    @Disabled("Predict the result first, then remove @Disabled")
    void proxyForAClass() {
        InvocationHandler doNothing = (proxy, method, args) -> null;

        assertDoesNotThrow(() -> Proxy.newProxyInstance(
                InMemoryRoomCatalog.class.getClassLoader(),
                new Class<?>[] { InMemoryRoomCatalog.class },
                doNothing));
    }
}

    Proxy: Protokolliere jeden Aufruf

    Implementier LoggingProxy.wrap mit Proxy.newProxyInstance und einem InvocationHandler: Der Handler trägt den Namen der aufgerufenen Methode in log ein und gibt den Aufruf an target weiter. InMemoryRoomCatalog änderst Du dabei nicht. Entferne an logsEveryCallAndDelegates das @Disabled und mach den Test grün.

    Miss zusätzlich mit System.nanoTime(), wie lange jeder Aufruf dauert, und gib es auf der Konsole aus.

    Hinweis: method.invoke(target, args) packt eine Ausnahme des Ziels in eine InvocationTargetException. Damit der Aufrufer die ursprüngliche Ausnahme sieht, wirf ihre getCause() weiter.

    Proxy: Sag den Proxy für eine Klasse vorher

    Der Test proxyForAClass trägt @Disabled. Er versucht, einen Proxy für die Klasse InMemoryRoomCatalog statt für das Interface zu erzeugen. Geh vor wie beim String: Erwartung notieren, @Disabled entfernen, starten, erklären, Assertion korrigieren.

    Für Schnelle

    • Schreib einen Mini-Testrunner: eine Annotation @MyTest für Methoden und eine Klasse mit main, die alle @MyTest-Methoden einer Klasse (Name als Argument) aufruft und passed oder failed ausgibt. Was muss der Runner tun, um die Klasse zu instanziieren?
    • Lass Deinen LoggingProxy statt List<String> die Argumente mitprotokollieren. Was steht in args bei einer Methode ohne Parameter?
