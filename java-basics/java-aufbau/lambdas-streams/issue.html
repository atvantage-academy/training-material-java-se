    Raumbuchungen mit Lambdas und Streams auswerten

    User Story

    Als Entwickler:in der Raumbuchung möchte ich bestehende Auswertungen als Pipelines formulieren, damit im Code steht, was ich wissen will, und nicht, wie die Schleife läuft.

    Lernziele
    • Du baust Schleifen zu Stream-Pipelines um, ohne dass sich ihr Ergebnis ändert – die Tests bleiben grün.
    • Du ersetzt anonyme Klassen durch Lambdas und Methodenreferenzen und kombinierst Bedingungen und Sortierungen.
    • Du nutzt removeIf, forEach, Map.merge und computeIfAbsent statt Collections von Hand zu durchlaufen.
    • Du wertest mit groupingBy, partitioningBy, toMap und joining aus.
    • Du ersetzt eine Rückgabe, die null sein kann, durch Optional.
    • Du rufst eine Methode mit Checked Exception aus einem Lambda auf.
    • Du verwendest assertAll und assertThrows aus JUnit und begründest, warum sie Lambdas brauchen.
    Definition of Done
    • Reports enthält keine for- oder while-Schleife mehr außer in roomIdsPerPerson, keine anonyme Klasse und kein null; findRoom liefert ein Optional<Room>.
    • In ReportsTest stehen keine anonymen Klassen mehr; alle Tests sind grün.
    • ObjectPoolTest prüft mit assertAll; personWithoutBirthDateIsRejected und secondBookingOfTheSameDayIsRejected erwarten ihre Exception mit assertThrows, ohne try-catch und fail – und sind grün.
    • In ExceptionsInLambdasTest trägt kein Test mehr @Disabled, alle sind grün, und executeAction liest die Datei über ein Lambda.
    • Der Maven-Build läuft ohne Fehler und ohne übersprungene Tests durch.
    • Du hast die Kontrollfragen beantwortet

    Die Raumbuchung kennt Räume und Buchungen, und es gibt schon eine Reihe von Auswertungen: Welche Räume sind groß genug, wer hat wie viele Stunden gebucht, was war am 1. Dezember belegt? Sie funktionieren – geschrieben mit Schleifen, anonymen Klassen und einem null für „nicht gefunden“. Du baust sie Schritt für Schritt auf Lambdas, Streams und Optional um. Die Tests sind von Anfang an grün und müssen es nach jedem Schritt bleiben.

    Reports.java – die Auswertungen, die Du umbaust:

    package aufbau.lambdas;

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Iterator;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.function.Predicate;

public final class Reports {

    // Names of all meeting rooms with at least 6 seats, smallest first, separated by commas
    public static String largeMeetingRoomNames(List<Room> rooms) {
        List<Room> result = new ArrayList<>();
        for (Room room : rooms) {
            if (room.type() == RoomType.MEETING && room.seats() >= 6) {
                result.add(room);
            }
        }
        Collections.sort(result, new Comparator<Room>() {
            @Override
            public int compare(Room first, Room second) {
                return Integer.compare(first.seats(), second.seats());
            }
        });
        StringBuilder names = new StringBuilder();
        for (Room room : result) {
            if (names.length() > 0) {
                names.append(", ");
            }
            names.append(room.name());
        }
        return names.toString();
    }

    // Names of all rooms that meet the condition, in the order of the list
    public static List<String> namesWhere(List<Room> rooms, Predicate<Room> condition) {
        List<String> names = new ArrayList<>();
        for (Room room : rooms) {
            if (condition.test(room)) {
                names.add(room.name());
            }
        }
        return names;
    }

    // Booked hours per person; cancelled bookings do not count
    public static Map<String, Integer> bookedHoursPerPerson(List<Booking> bookings) {
        List<Booking> active = new ArrayList<>(bookings);
        Iterator<Booking> iterator = active.iterator();
        while (iterator.hasNext()) {
            if (iterator.next().isCancelled()) {
                iterator.remove();
            }
        }
        Map<String, Integer> hours = new HashMap<>();
        for (Booking booking : active) {
            Integer sum = hours.get(booking.bookedBy());
            if (sum == null) {
                hours.put(booking.bookedBy(), booking.hours());
            } else {
                hours.put(booking.bookedBy(), sum + booking.hours());
            }
        }
        return hours;
    }

    // Ids of the booked rooms per person; cancelled bookings do not count
    public static Map<String, Set<String>> roomIdsPerPerson(List<Booking> bookings) {
        Map<String, Set<String>> roomIds = new HashMap<>();
        for (Booking booking : bookings) {
            if (!booking.isCancelled()) {
                Set<String> ids = roomIds.get(booking.bookedBy());
                if (ids == null) {
                    ids = new HashSet<>();
                    roomIds.put(booking.bookedBy(), ids);
                }
                ids.add(booking.roomId());
            }
        }
        return roomIds;
    }

    // Number of rooms per room type
    public static Map<RoomType, Long> roomCountPerType(List<Room> rooms) {
        Map<RoomType, Long> counts = new HashMap<>();
        for (Room room : rooms) {
            Long count = counts.get(room.type());
            if (count == null) {
                counts.put(room.type(), 1L);
            } else {
                counts.put(room.type(), count + 1);
            }
        }
        return counts;
    }

    // Names of the rooms with at least the given number of seats (true) and with fewer (false)
    public static Map<Boolean, List<String>> namesBySeatsAtLeast(List<Room> rooms, int seats) {
        List<String> large = new ArrayList<>();
        List<String> small = new ArrayList<>();
        for (Room room : rooms) {
            if (room.seats() >= seats) {
                large.add(room.name());
            } else {
                small.add(room.name());
            }
        }
        Map<Boolean, List<String>> names = new HashMap<>();
        names.put(true, large);
        names.put(false, small);
        return names;
    }

    // Names of the rooms booked on the given date, each room once
    public static List<String> roomNamesBookedOn(List<Room> rooms, List<Booking> bookings, LocalDate date) {
        List<String> names = new ArrayList<>();
        for (Booking booking : bookings) {
            if (booking.date().equals(date)) {
                for (Room room : rooms) {
                    if (room.id().equals(booking.roomId()) && !names.contains(room.name())) {
                        names.add(room.name());
                    }
                }
            }
        }
        return names;
    }

    // The room with the given id, or null if there is none
    public static Room findRoom(List<Room> rooms, String id) {
        for (Room room : rooms) {
            if (room.id().equals(id)) {
                return room;
            }
        }
        return null;
    }

    // The name of the room with the given id, or "unknown"
    public static String roomNameOrUnknown(List<Room> rooms, String id) {
        Room room = findRoom(rooms, id);
        if (room == null) {
            return "unknown";
        }
        return room.name();
    }

    private Reports() {
    }
}

    Kopiere den Test ins Package aufbau.lambdas unter src/test/java.

    ReportsTest.java:

    package aufbau.lambdas;

import static aufbau.lambdas.SampleData.BOOKINGS;
import static aufbau.lambdas.SampleData.ROOMS;
import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertNull;

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.function.Predicate;
import org.junit.jupiter.api.Test;

class ReportsTest {

    @Test
    void largeMeetingRoomNames() {
        assertEquals("Berlin, Kiel, Hamburg", Reports.largeMeetingRoomNames(ROOMS));
    }

    @Test
    void namesOfLargeTrainingRooms() {
        Predicate<Room> isTrainingRoom = new Predicate<Room>() {
            @Override
            public boolean test(Room room) {
                return room.type() == RoomType.TRAINING;
            }
        };
        Predicate<Room> hasAtLeast16Seats = new Predicate<Room>() {
            @Override
            public boolean test(Room room) {
                return room.seats() >= 16;
            }
        };

        List<String> names = Reports.namesWhere(ROOMS, isTrainingRoom.and(hasAtLeast16Seats));

        assertEquals(List.of("Munich", "Bremen"), names);
    }

    @Test
    void roomsSortedByFloorThenLargestFirst() {
        Comparator<Room> byFloorThenLargestFirst = new Comparator<Room>() {
            @Override
            public int compare(Room first, Room second) {
                int byFloor = Integer.compare(first.floor(), second.floor());
                if (byFloor != 0) {
                    return byFloor;
                }
                return Integer.compare(second.seats(), first.seats());
            }
        };

        List<Room> sorted = new ArrayList<>(ROOMS);
        sorted.sort(byFloorThenLargestFirst);

        assertEquals("Munich", sorted.get(0).name());
        assertEquals("Hamburg", sorted.get(1).name());
        assertEquals("Berlin", sorted.get(2).name());
    }

    @Test
    void bookedHoursPerPersonIgnoresCancelledBookings() {
        Map<String, Integer> hours = Reports.bookedHoursPerPerson(BOOKINGS);

        assertEquals(Map.of("ada", 4, "linus", 2, "grace", 16), hours);
    }

    @Test
    void roomIdsPerPersonOfActiveBookings() {
        Map<String, Set<String>> roomIds = Reports.roomIdsPerPerson(BOOKINGS);

        assertEquals(Set.of("R101"), roomIds.get("ada"));
        assertEquals(Set.of("R101", "R202"), roomIds.get("linus"));
        assertEquals(Set.of("R103", "R301"), roomIds.get("grace"));
    }

    @Test
    void roomCountPerType() {
        assertEquals(Map.of(RoomType.MEETING, 4L, RoomType.TRAINING, 3L, RoomType.OFFICE, 1L),
                Reports.roomCountPerType(ROOMS));
    }

    @Test
    void namesBySeatsAtLeast10() {
        Map<Boolean, List<String>> names = Reports.namesBySeatsAtLeast(ROOMS, 10);

        assertEquals(List.of("Hamburg", "Munich", "Cologne", "Bremen"), names.get(true));
        assertEquals(List.of("Berlin", "Dresden", "Leipzig", "Kiel"), names.get(false));
    }

    @Test
    void roomNamesBookedOnFirstOfDecember() {
        List<String> names = Reports.roomNamesBookedOn(ROOMS, BOOKINGS, LocalDate.of(2026, 12, 1));

        assertEquals(List.of("Berlin"), names);
    }

    @Test
    void findRoom() {
        assertEquals("Bremen", Reports.findRoom(ROOMS, "R301").name());
        assertNull(Reports.findRoom(ROOMS, "R999"));
    }

    @Test
    void roomNameOrUnknown() {
        assertEquals("Bremen", Reports.roomNameOrUnknown(ROOMS, "R301"));
        assertEquals("unknown", Reports.roomNameOrUnknown(ROOMS, "R999"));
    }

    @Test
    void cancellationOfFirstBookingOfRoomR102() {
        LocalDate cancelledOn = BOOKINGS.stream()
                .filter(booking -> booking.roomId().equals("R102"))
                .findFirst()
                .flatMap(Booking::cancellation)
                .orElseThrow();

        assertEquals(LocalDate.of(2026, 11, 28), cancelledOn);
    }
}

    Baue erneut mit Maven.

    Alle Tests in ReportsTest sind grün. Das bleiben sie: Starte nach jedem der folgenden Schritte erneut mit Maven. Was sich ändert, ist nur, wie der Code es ausdrückt.

    Bau die Schleife zur Pipeline um

    Lies largeMeetingRoomNames und sag in einem Satz, was die Methode liefert. Bau sie dann zu einer Stream-Pipeline um: filtern, sortieren, auf den Namen abbilden, mit Komma verbinden. Das Bild dazu – ein Fließband mit Maschinen und einem Eimer am Ende – zeigt die Visualisierung Lambdas, Streams und Optional.

    Hinweis: Für die Sortierung gibt es Comparator.comparingInt(…), fürs Verbinden Collectors.joining(…).

    Ersetz die anonymen Klassen durch Lambdas

    In ReportsTest stehen drei anonyme Klassen: zwei Predicate<Room> in namesOfLargeTrainingRooms und ein Comparator<Room> in roomsSortedByFloorThenLargestFirst.

    • Schreib die beiden Bedingungen als Lambdas. Sieh Dir an, wie sie mit and zu einer Bedingung werden.
    • Bau den Comparator aus Comparator.comparingInt(Room::floor) und thenComparing zusammen – innerhalb eines Stockwerks kommt der größte Raum zuerst.
    • Bau namesWhere zur Pipeline um: Die Bedingung, die hereinkommt, passt direkt in filter.

    Hinweis: thenComparing nimmt auch einen zweiten Comparator für die Richtung – reversed() dreht ihn um.

    Lass die Collections-API die Schleifen schreiben

    Nicht alles muss ein Stream werden. Collections und Maps haben eigene Methoden, die ein Lambda nehmen:

    • In bookedHoursPerPerson: Ersetz den Iterator durch removeIf und die Summe je Person durch forEach mit Map.merge.
    • In roomIdsPerPerson: Ersetz das Prüfen auf null und das Anlegen der Menge durch computeIfAbsent. Die Schleife darf bleiben.

    Werte mit Collectors aus

    Bau mit Streams um:

    • roomCountPerType mit Collectors.groupingBy und einem nachgelagerten Collector,
    • namesBySeatsAtLeast mit Collectors.partitioningBy – die Werte sind Namen, keine Räume,
    • roomNamesBookedOn: Bau Dir zuerst mit Collectors.toMap eine Map von Raum-ID zu Raumname, dann bildest Du die Buchungen des Tages darauf ab. Jeder Raum steht nur einmal im Ergebnis – statt contains gibt es dafür eine Maschine auf dem Band.

    Ersetz null durch Optional

    findRoom liefert null, wenn es den Raum nicht gibt; roomNameOrUnknown muss das wissen und prüfen.

    1. Ändere den Rückgabetyp von findRoom auf Optional<Room> und bau die Methode zur Pipeline um.
    2. Der Compiler meldet jetzt die Stellen, die mit null gerechnet haben. Bau roomNameOrUnknown ohne if um, mit map und orElse.
    3. Pass den Test findRoom an: statt .name() und assertNull jetzt map, orElse und isEmpty – ohne isPresent und get.

    Der Test cancellationOfFirstBookingOfRoomR102 arbeitet schon mit Optional. Lies ihn und erklär, warum dort flatMap steht.

    Hinweis: Optional ist ein Rückgabetyp. Als Feld oder Parameter macht es den Code nicht sicherer, nur länger – Booking speichert deshalb cancelledOn und gibt erst in cancellation() ein Optional heraus.

    Teste mit Lambdas: assertAll und assertThrows

    JUnit nimmt an zwei Stellen Lambdas entgegen: Assertions.assertAll und Assertions.assertThrows. Sieh Dir beide Methoden in der Javadoc oder im JUnit User Guide an und bau damit Tests aus den früheren Übungen um:

    • ObjectPoolTest im Package aufbau.wrapper: Jeder Test führt alle seine Assertions aus und meldet alle, die scheitern – nicht nur die erste.
    • personWithoutBirthDateIsRejected in aufbau.exceptions und secondBookingOfTheSameDayIsRejected in aufbau.junit: Sie erwarten ihre Exception ohne try-catch und fail.

    Starte die Tests danach in der IDE; sie müssen grün bleiben. Ändere zur Probe zwei Erwartungen in einem assertAll – wie viele Fehlschläge meldet JUnit? Nimm die Änderung danach zurück.

    Ruf eine Methode mit Checked Exception aus einem Lambda auf

    readFile wirft eine IOException. Kopiere die Klasse ins Package aufbau.lambdas unter src/test/java.

        assertThrows(IOException.class, () -> executeAction(missingFile));

        // Supplier<String> reader = () -> readFile(file);
        // return reader.get();
        return readFile(file);
    }

    private static List<String> readAll(List<Path> files) {
        // return files.stream().map(file -> readFile(file)).toList();

        return Files.readString(file);

    Ändere nur executeAction und readAll:

    • executeAction soll die Datei über ein Lambda lesen, wie im Kommentar. Entferne die Kommentarzeichen und lies die Meldung des Compilers. Finde einen Weg, bei dem die IOException trotzdem beim Aufrufer ankommt – der Test exceptionReachesTheCaller bleibt grün.
    • readAll soll alle Dateien mit einem Stream lesen, wie im Kommentar. Hier soll eine fehlende Datei als UncheckedIOException ankommen. Entferne an den beiden Tests zu readAll das @Disabled.

    Hinweis: Zwei Wege sind üblich: ein eigenes funktionales Interface, dessen Methode throws IOException deklariert, oder die IOException im Lambda fangen und in eine UncheckedIOException einpacken. Probier beide aus.

    Für Schnelle

    • Starte roomCountPerType mit parallelStream() statt stream(). Ändert sich das Ergebnis? Wann lohnt sich das – bei acht Räumen?
    • Schreib mit Collector.of(…) einen eigenen Collector, der die Namen von Räumen als "Berlin | Kiel | Hamburg" verbindet – und vergleich ihn mit joining.
