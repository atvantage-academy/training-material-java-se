    Wrapper-Klassen und Autoboxing: Zahlen, die keine sind

    User Story

    Als Java-Entwickler:in möchte ich wissen, wann aus einem int ein Integer wird und was das kostet, damit mich ==, Laufzeiten und Rundungsfehler nicht überraschen.

    Lernziele
    • Du sagst voraus, wann == bei Strings und Integer wahr ist, und begründest es mit String-Pool und Integer-Cache.
    • Du misst den Preis von Autoboxing in einer Schleife.
    • Du erkennst, welche Überladung von remove und Arrays.asList der Compiler wählt.
    • Du rechnest Geldbeträge ohne Rundungsfehler.
    Definition of Done
    • Das Package aufbau.wrapper enthält die fünf Tests dieser Übung, keiner trägt mehr @Disabled.
    • Vor jedem Start hast Du Deine Erwartung notiert; jede Assertion beschreibt jetzt das tatsächliche Verhalten, und der Maven-Build läuft grün.
    • Du hast die beiden Laufzeiten aus AutoboxingPerformanceTest notiert und kannst den Unterschied erklären.
    • Ein zweiter Test in MoneyCountTest rechnet in Cent und kommt auf 15 Kaugummis und 0 Cent Rest.

    int und Integer sehen sich ähnlich, und meist wandelt Java still zwischen ihnen um. Die folgenden Tests zeigen, wo diese Stille teuer oder falsch wird. Jeder kompiliert, ist aber mit @Disabled abgeschaltet.

    Hinweis: Ein Test bricht an der ersten Assertion ab, die scheitert – die Assertions danach laufen gar nicht mehr. Korrigier sie und starte erneut; so arbeitest Du Dich Assertion für Assertion vor.

    Arbeitsschritte

    Das Paket anlegen

    Im Ordner src/test/java Deines Projekts java-aufbau lege das Package aufbau.wrapper an. Alle Tests dieser Übung kommen dort hinein.

    Gleichheit mit == vorhersagen

    Speichere den Test als ObjectPoolTest.java:

    package aufbau.wrapper;

import static org.junit.jupiter.api.Assertions.assertEquals;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

@Disabled("Predict the result first, then remove @Disabled")
class ObjectPoolTest {

    @Test
    void stringLiterals() {
        String s1 = "text";
        String s2 = "text";

        assertEquals(false, s1 == s2);
        assertEquals(false, new String(s1) == s2);
        assertEquals(false, new String(s1).intern() == s2);
    }

    @Test
    void concatenatedStrings() {
        String s1 = "text";
        String te = "te";
        final String xt = "xt";

        String s3 = "te" + "xt";
        String s4 = te + "xt";
        String s5 = "te" + xt;

        assertEquals(false, s1 == s3);
        assertEquals(false, s1 == s4);
        assertEquals(false, s1 == s4.intern());
        assertEquals(false, s1 == s5);
    }

    @Test
    void boxedIntegers() {
        Integer i1 = 4;
        Integer i2 = 4;
        Integer i3 = 128;
        Integer i4 = 128;
        Integer i5 = -129;
        Integer i6 = -129;

        assertEquals(false, i1 == i2);
        assertEquals(false, i3 == i4);
        assertEquals(false, i5 == i6);
        assertEquals(false, i5.equals(i6));
    }
}

    Notier für jede Assertion Deine Erwartung, entferne @Disabled und starte den Test in der IDE.

    Den Preis von Autoboxing messen

    Beide Tests summieren die Zahlen von 0 bis Integer.MAX_VALUE, einmal in einem long, einmal in einem Long. Bevor Du startest: Schätze, um welchen Faktor die zweite Variante langsamer ist. Speichere den Test als AutoboxingPerformanceTest.java:

    package aufbau.wrapper;

import static org.junit.jupiter.api.Assertions.assertEquals;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

@Disabled("Predict the result first, then remove @Disabled")
class AutoboxingPerformanceTest {

    static final long EXPECTED_SUM = (long) Integer.MAX_VALUE * (Integer.MAX_VALUE - 1) / 2;

    @Test
    void sumWithPrimitiveLong() {
        long start = System.nanoTime();
        long sum = 0L;
        for (int i = 0; i < Integer.MAX_VALUE; i++) {
            sum += i;
        }
        long millis = (System.nanoTime() - start) / 1_000_000;
        System.out.println("long: " + millis + " ms");
        assertEquals(EXPECTED_SUM, sum);
    }

    @Test
    void sumWithWrapperLong() {
        long start = System.nanoTime();
        Long sum = 0L;
        for (int i = 0; i < Integer.MAX_VALUE; i++) {
            sum += i;
        }
        long millis = (System.nanoTime() - start) / 1_000_000;
        System.out.println("Long: " + millis + " ms");
        assertEquals(EXPECTED_SUM, sum);
    }
}

    Entferne @Disabled und starte den Test in der IDE.

    Die Laufzeiten stehen in der Konsole. Vergleiche sie mit Deiner Schätzung.

    Ein Element aus einer Liste entfernen

    Speichere den Test als ListRemoveTest.java:

    package aufbau.wrapper;

import static org.junit.jupiter.api.Assertions.assertEquals;

import java.util.ArrayList;
import java.util.Collection;
import java.util.List;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

@Disabled("Predict the result first, then remove @Disabled")
class ListRemoveTest {

    @Test
    void removeFromList() {
        List<Integer> numbers = new ArrayList<>();
        numbers.add(1);
        numbers.add(2);
        numbers.add(3);

        numbers.remove(2);

        assertEquals(List.of(1, 3), numbers);
    }

    @Test
    void removeFromCollection() {
        Collection<Integer> numbers = new ArrayList<>();
        numbers.add(1);
        numbers.add(2);
        numbers.add(3);

        numbers.remove(2);

        assertEquals(List.of(1, 3), numbers);
    }
}

    Notier Deine Erwartungen, entferne @Disabled und starte den Test in der IDE.

    Ein Array in eine Liste verwandeln

    Speichere den Test als ArraysAsListTest.java:

    package aufbau.wrapper;

import static org.junit.jupiter.api.Assertions.assertEquals;

import java.util.Arrays;
import java.util.List;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

@Disabled("Predict the result first, then remove @Disabled")
class ArraysAsListTest {

    @Test
    void listFromObjectArray() {
        Object[] numbers = { 1, 2, 3 };

        List<?> list = Arrays.asList(numbers);

        assertEquals(3, list.size());
    }

    @Test
    void listFromIntArray() {
        int[] numbers = { 1, 2, 3 };

        List<?> list = Arrays.asList(numbers);

        assertEquals(3, list.size());
    }
}

    Notier Deine Erwartungen, entferne @Disabled und starte den Test in der IDE.

    Hinweis: Wenn Du wissen willst, was in der Liste steckt: Ersetze List<?> durch var und lass Dir in der IDE den Typ anzeigen.

    Kaugummis kaufen

    Du hast 10,95 €, ein Kaugummi kostet 0,73 €. Wie viele kannst Du kaufen, und wie viel Geld bleibt übrig? Speichere den Test als MoneyCountTest.java:

    package aufbau.wrapper;

import static org.junit.jupiter.api.Assertions.assertEquals;

import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

@Disabled("Predict the result first, then remove @Disabled")
class MoneyCountTest {

    // You have 10.95 EUR. A chewing gum costs 0.73 EUR.
    // How many can you buy, and how much money is left?
    @Test
    void buyChewingGum() {
        double money = 10.95;
        double price = 0.73;
        int count = 0;
        while (money >= price) {
            count++;
            money -= price;
        }

        assertEquals(15, count);
        assertEquals(0.0, money);
    }
}

    Notier Deine Erwartung, entferne @Disabled und starte den Test in der IDE.

    Schreib danach in derselben Klasse einen zweiten Test buyChewingGumInCents, der dieselbe Rechnung mit long-Werten in Cent ausführt, und prüfe Anzahl und Rest.

    Hinweis: Wer lieber mit BigDecimal rechnet: Erzeuge die Werte aus einem String (new BigDecimal("10.95")) und vergleiche mit compareTo.
