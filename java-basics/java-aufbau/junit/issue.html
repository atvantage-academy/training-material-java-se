    Den Raum mit JUnit testen

    User Story

    Als Java-Entwickler:in möchte ich das Verhalten einer Klasse in Tests festhalten, damit ich merke, wenn es sich ändert.

    Lernziele
    • Du schreibst Tests mit assertEquals, assertTrue, assertFalse, @BeforeEach und @DisplayName.
    • Du überzeugst Dich, dass ein Test wirklich etwas prüft, indem Du ihn absichtlich rot werden lässt.
    Definition of Done
    • Room liegt im Package aufbau.junit unter src/main/java.
    • RoomTest prüft eine Buchung, Nummer, Name und Kapazität und einen ersten Fall von canHost.
    • Du hast mindestens einen Test absichtlich rot werden lassen und die Änderung zurückgenommen.
    • Der Maven-Build meldet alle Tests grün.
    • Du hast die Kontrollfragen beantwortet

    Das Projekt steht, und JUnit ist drin. Jetzt schreibst Du die ersten Tests – für einen Raum der Raumbuchung, die sich durch den Kurs zieht.

    Arbeitsschritte

    Einen Raum der Raumbuchung übernehmen

    Im Ordner src/main/java lege das Package aufbau.junit an und darin Room.java:

    package aufbau.junit;

import java.time.LocalDate;
import java.util.HashSet;
import java.util.Set;

public class Room {

    private final String number;
    private final String name;
    private final int capacity;
    private final Set<LocalDate> bookedDays = new HashSet<>();

    public Room(String number, String name, int capacity) {
        if (capacity < 1) {
            throw new IllegalArgumentException("capacity must be at least 1, but was " + capacity);
        }
        this.number = number;
        this.name = name;
        this.capacity = capacity;
    }

    public String getNumber() {
        return number;
    }

    public String getName() {
        return name;
    }

    public int getCapacity() {
        return capacity;
    }

    public boolean canHost(int persons) {
        return persons > 0 && persons <= capacity;
    }

    public void book(LocalDate day) {
        bookedDays.add(day);
    }

    public boolean isBooked(LocalDate day) {
        return bookedDays.contains(day);
    }
}

    Den Raum testen

    Im Ordner src/test/java lege ebenfalls das Package aufbau.junit an und darin RoomTest.java. Sie bringt schon einen frischen Raum für jeden Test und einen ersten Test mit:

    package aufbau.junit;

import static org.junit.jupiter.api.Assertions.assertFalse;
import static org.junit.jupiter.api.Assertions.assertTrue;

import java.time.LocalDate;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

class RoomTest {

    private static final LocalDate MONDAY = LocalDate.of(2026, 3, 2);

    private Room room;

    @BeforeEach
    void createRoom() {
        room = new Room("R101", "Seminar 1", 12);
    }

    @Test
    void bookingMarksTheDayAsBooked() {
        assertFalse(room.isBooked(MONDAY));
        room.book(MONDAY);
        assertTrue(room.isBooked(MONDAY));
    }
}

    Ergänze die Klasse um die folgenden zwei Tests und starte die Testklasse nach jedem Test in der IDE.

    1. Nummer, Name und Kapazität. Ein neuer Raum behält Nummer, Name und Kapazität. Gib dem Test mit @DisplayName einen Namen, der im Bericht lesbar ist.

    Lösung

    Dazu die Importe org.junit.jupiter.api.DisplayName und statisch Assertions.assertEquals.

    @Test
@DisplayName("A new room keeps its number, name and capacity")
void newRoomKeepsNumberNameAndCapacity() {
    assertEquals("R101", room.getNumber());
    assertEquals("Seminar 1", room.getName());
    assertEquals(12, room.getCapacity());
}

    2. Platz für eine Gruppe. Der Raum für 12 Personen kann eine Gruppe von 6 Personen aufnehmen.

    Lösung 
    @Test
void roomForTwelveCanHostSix() {
    assertTrue(room.canHost(6));
}

    Prüf zwischendurch, ob ein Test wirklich etwas prüft: Ändere eine Erwartung absichtlich, sieh ihn rot werden und nimm die Änderung zurück.

    Hinweis: Ein Test bricht an der ersten Assertion ab, die scheitert – die Assertions danach laufen gar nicht mehr. Ändern sich im ersten Test Nummer und Name, meldet JUnit nur die Nummer; den Namen siehst Du erst im nächsten Lauf.
