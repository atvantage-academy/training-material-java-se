    Dynamic Proxy: die markierten Aufrufe des Raumkatalogs protokollieren

    User Story

    Als Entwickler:in der Raumbuchung möchte ich ein Protokoll um den Raumkatalog legen, ohne seinen Code zu ändern, damit ich verstehe, wie Frameworks Transaktionen, Protokolle und Mocks um meine Objekte legen.

    Lernziele
    • Du erzeugst mit Proxy.newProxyInstance und einem InvocationHandler einen Stellvertreter für ein Interface.
    • Du wertest im Handler die Annotation der aufgerufenen Methode aus.
    • Du gibst den Aufruf an das Ziel weiter und reichst dessen Ausnahmen unverändert durch.
    • Du erklärst, warum java.lang.reflect.Proxy nur Interfaces kann.
    Definition of Done
    • LoggingProxy.wrap liefert einen Proxy, der die mit @Logged markierten Aufrufe protokolliert und alle Aufrufe an das Ziel weitergibt; InMemoryRoomCatalog ist unverändert.
    • Eine Ausnahme des Ziels kommt beim Aufrufer als dieselbe Ausnahme an.
    • Die Vorhersage in proxyForAClass hast Du notiert, geprüft und die Assertion korrigiert.
    • Der Maven-Build läuft ohne Fehler und ohne übersprungene Tests durch.
    • Du hast die Kontrollfragen beantwortet

    In der letzten Übung hast Du die Methoden des Raumkatalogs mit @Logged markiert und die Markierung per Reflection ausgelesen. Jetzt soll sie wirken: Jeder Aufruf einer markierten Methode landet im Protokoll – ohne dass Du InMemoryRoomCatalog änderst und ohne dass der Aufrufer etwas davon merkt. Dafür legst Du einen Dynamic Proxy um den Katalog. Wie ein Aufruf durch den Proxy läuft, zeigt die Visualisierung Dynamic Proxy.

    Die Übung baut auf dem Package aufbau.annotations aus Eigene Annotation: @Logged schreiben und per Reflection auslesen auf.

    Arbeitsschritte

    Kopiere das Gerüst und den Test

    Kopiere die Klasse ins Package aufbau.annotations unter src/main/java.

import java.util.List;

public final class LoggingProxy {

    // returns a stand-in for target that writes an entry to log for every call of a method
    // marked with @Logged: its description, followed by the arguments if withArguments is set
    public static <T> T wrap(T target, Class<T> type, List<String> log) {
        throw new UnsupportedOperationException("TODO");
    }

    private LoggingProxy() {
    }
}

    Kopiere den Test ins Package aufbau.annotations unter src/test/java.

    LoggingProxyTest.java:

    package aufbau.annotations;

import static org.junit.jupiter.api.Assertions.assertDoesNotThrow;
import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Proxy;
import java.util.ArrayList;
import java.util.List;
import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;

class LoggingProxyTest {

    @Test
    @Disabled("Remove @Disabled once you have implemented LoggingProxy.wrap")
    void logsTheMarkedCallsAndDelegates() {
        List<String> log = new ArrayList<>();
        RoomCatalog catalog = LoggingProxy.wrap(new InMemoryRoomCatalog(), RoomCatalog.class, log);

        catalog.add(new Room("R101", "Berlin", 6));
        String name = catalog.find("R101").orElseThrow().name();
        int size = catalog.size();

        assertEquals("Berlin", name);
        assertEquals(1, size);
        assertEquals(List.of("add a room", "look up a room [R101]"), log);
    }

    @Test
    @Disabled("Remove @Disabled once you have implemented LoggingProxy.wrap")
    void exceptionOfTheTargetReachesTheCaller() {
        RoomCatalog catalog = LoggingProxy.wrap(new InMemoryRoomCatalog(), RoomCatalog.class, new ArrayList<>());
        catalog.add(new Room("R101", "Berlin", 6));

        assertThrows(IllegalStateException.class, () -> catalog.add(new Room("R101", "Berlin", 6)));
    }

    @Test
    @Disabled("Predict the result first, then remove @Disabled")
    void proxyForAClass() {
        InvocationHandler doNothing = (proxy, method, args) -> null;

        assertDoesNotThrow(() -> Proxy.newProxyInstance(
                InMemoryRoomCatalog.class.getClassLoader(),
                new Class<?>[] { InMemoryRoomCatalog.class },
                doNothing));
    }
}

    Protokolliere die markierten Aufrufe

    Implementier LoggingProxy.wrap mit Proxy.newProxyInstance und einem InvocationHandler. Der Handler

    1. holt sich die Annotation @Logged der aufgerufenen Methode,
    2. trägt, falls sie da ist, ihre Beschreibung in log ein – bei withArguments gefolgt von den Argumenten, etwa look up a room [R101],
    3. gibt den Aufruf an target weiter und liefert dessen Ergebnis zurück.

    Entferne an logsTheMarkedCallsAndDelegates das @Disabled und mach den Test grün.

    Hinweis: Der Handler bekommt die aufgerufene Method des Interfaces – genau dort steht @Logged. Die Argumente liegen als Object[] vor; Arrays.toString(args) macht daraus [R101].

    Reich die Ausnahmen des Ziels weiter

    Entferne an exceptionOfTheTargetReachesTheCaller das @Disabled und starte den Test. Welche Ausnahme kommt beim Aufrufer an, und woher stammt sie? Ändere den Handler so, dass die IllegalStateException des Katalogs unverändert ankommt.

    Hinweis: method.invoke(target, args) packt eine Ausnahme des Ziels in eine InvocationTargetException. Ihre Ursache liefert getCause().

    Sag den Proxy für eine Klasse vorher

    Der Test proxyForAClass versucht, einen Proxy für die Klasse InMemoryRoomCatalog statt für das Interface zu erzeugen.

    1. Notier Deine Erwartung: Klappt das?
    2. Entferne @Disabled und starte den Test.
    3. Erklär das Ergebnis.
    4. Korrigier die Assertion auf das tatsächliche Verhalten, bis der Test grün ist.

    Für Schnelle

    • Miss im Handler mit System.nanoTime(), wie lange jeder Aufruf dauert, und gib es auf der Konsole aus.
    • Ruf catalog.toString() auf. Was landet im Protokoll – und läuft der Aufruf durch Deinen Handler?
