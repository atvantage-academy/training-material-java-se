    Drei Objekte in diesem Raum

    Als Entwickler:in möchte ich an alltäglichen Dingen sehen, was ein Objekt ausmacht, damit mir der Sprung vom prozeduralen Denken zur Objektorientierung leichter fällt.

    Hinweis: Hier wird nicht programmiert. Zettel und Stift genügen – oder ein Notizfenster, wenn Du online dabei bist.

    Lernziele

    Du…

    • benennst an alltäglichen Dingen deren Eigenschaften (Zustand) und eine Fähigkeit (Verhalten).
    • unterscheidest, was ein Ding hat und was man mit ihm tun kann.
    • beschreibst Objekte in einer Form, die sich später in Code überführen lässt.

    Definition of Done

    • Du hast drei Dinge aus diesem Raum notiert.
    • Zu jedem Ding stehen drei Eigenschaften und eine Sache, die es kann (oder die man damit tun kann).
    • Du kannst Deine Auswahl kurz vorstellen.

    Arbeitsschritte

    Drei Dinge auswählen

    Sieh Dich im Raum um und such Dir drei Dinge aus – irgendetwas, das Du siehst. Es muss nichts mit Software zu tun haben.

    Jedes Ding beschreiben

    Notiere zu jedem Ding:

    • drei Eigenschaften – was hat es, wie ist es?
    • eine Fähigkeit – was kann es, oder was kann man damit tun?

    Beispiel:

    Kaffeetasse

    • Eigenschaften: Farbe = weiß, Füllstand = 200 ml, Fassungsvermögen = 300 ml
    • Kann: gefüllt werden (füllen)

    Schreib die Eigenschaften ruhig als Name = Wert auf – so wie oben. Das macht später den Unterschied zwischen „was ist das für ein Ding?“ und „welches genau meine ich?“ sichtbar.

    Hinweis: Wenn Dir mehr Fähigkeiten einfallen: notiere sie, aber eine genügt. Wichtiger ist, dass die drei Dinge unterschiedlich sind.

    Reflexionsfragen

    • Woran hast Du gemerkt, ob etwas eine Eigenschaft oder eine Fähigkeit ist?
    • Gibt es in diesem Raum zwei Dinge, die Du gleich beschrieben hast – und was unterscheidet sie dann noch?
