    Einen gemeinsamen Vertrag per Interface einführen

    Als Entwickler:in möchte ich alles, was eine fachliche ID besitzt, über einen gemeinsamen Vertrag ansprechen, damit ich Hilfscode einmal schreibe und für Kunde und Konto gleichermaßen nutze.

    Lernziele

    Du…

    • definierst ein Interface und implementierst es in mehreren Klassen.
    • schreibst eine Methode, die gegen das Interface statt gegen eine konkrete Klasse arbeitet.
    • grenzt Interface und abstrakte Klasse gegeneinander ab.

    Definition of Done

    • Es gibt ein Interface Identifizierbar mit einer Methode getId().
    • Kunde und Konto implementieren Identifizierbar.
    • Es gibt eine Methode, die ein Identifizierbar entgegennimmt und dessen ID nutzt (z. B. beschreibe(Identifizierbar)).
    • Der Aufruf funktioniert mit Kunde- und Konto-Objekten.
    • Du hast die Reflexionsfragen schriftlich beantwortet.

    Arbeitsschritte

    Das Interface definieren

    Lege ein Interface an, das den Vertrag „hat eine ID“ beschreibt.

    public interface Identifizierbar {
  String getId();
}

    Hinweis: Ein Interface beschreibt nur was möglich ist, nicht wie. Es enthält (klassisch) keine Felder und keine Implementierung.

    Den Vertrag implementieren

    Lass Kunde und Konto Identifizierbar implementieren und getId() passend zurückgeben.

    Hinweis: Die Identität heißt je Klasse anders – beim Kunden die nummer, beim Konto die iban. Genau das versteckt der gemeinsame Vertrag: getId() liefert sie einheitlich als String.

    Gegen das Interface programmieren

    Schreibe eine Methode, die ein Identifizierbar annimmt – nicht einen konkreten Typ.

    static void beschreibe(Identifizierbar element) {
  System.out.println("Objekt mit ID: " + element.getId());
}

    Reflexionsfragen

    • Warum kann beschreibe mit Kunden und Konten umgehen, ohne deren konkrete Klasse zu kennen?
    • Wann würdest Du statt eines Interfaces eine abstrakte Klasse wählen?
    • Welche künftige Erweiterung wird durch „Programmieren gegen das Interface“ einfacher?
